# 🧵 Filament Flow

מערכת Streamlit לניהול מלאי פילמנטים בצורה נוחה, מהירה ועם חוויית משתמש טובה.

## 🚀 התקנה והרצה

1. התקן תלויות:
```bash
pip install -r requirements.txt
```

2. הרץ את האפליקציה:
```bash
streamlit run app.py
```

3. פתח בדפדפן:
`http://localhost:8501`

## ✨ מה יש במערכת

- 📊 **דשבורד חכם** עם מדדים חשובים (סלילים במלאי, צריכה יומית, התראות מלאי נמוך)
- ➕ **הוספת סלילים** עם פרטים מלאים: חומר, צבע, מותג, טמפרטורות ומיקום
- 🛠️ **רישום שימוש מהיר** לכל פרויקט ועדכון אוטומטי של יתרת גרמים
- 📦 **ניהול מלאי** בטבלה נוחה + מחיקת סלילים
- 📈 **אנליטיקה** עם היסטוריית שימוש וגרף צריכה לפי פילמנט

## 💾 שמירת נתונים

הנתונים נשמרים מקומית בקובץ:
- `data/filaments.json`

כך שגם אחרי רענון/הפעלה מחדש הנתונים נשארים.

## 🛠️ טכנולוגיות

- Streamlit
- Pandas
- Python 3.8+
